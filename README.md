# PayFlow – Android Pay Calculator

PayFlow is a simple Android application developed for COMP3074 Assignment 1 using Kotlin and XML.

## Features

- Calculate regular pay based on hours worked and hourly rate.
- Calculate overtime pay at 1.5x for hours exceeding 40.
- Calculate total pay and tax.
- Validate user inputs.
- View student information on a separate About screen.
- Navigate between activities using Android's ActionBar.

## Technologies

- Kotlin
- XML
- Android SDK
- Gradle

## How to Run

1. Open the project in an Android development environment.
2. Make sure JDK 17 and Android SDK 35 are installed.
3. Build the application using:

   `.\gradlew.bat assembleDebug`
